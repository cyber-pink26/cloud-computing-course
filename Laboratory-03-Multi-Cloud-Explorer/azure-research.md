
# Microsoft Azure Research

## 1. Brief Overview

Microsoft Azure is Microsoft's cloud computing platform. It provides cloud services for computing, storage, databases, networking, artificial intelligence, security, analytics, and application development.

## 2. Global Infrastructure

Azure provides a global infrastructure made up of regions and availability-related infrastructure designed to help organizations deploy applications close to their users and maintain reliable services.

## 3. Cloud Management Console

The Azure portal is a web-based management interface for Azure resources. Administrators and developers can create, configure, monitor, and manage cloud resources through the portal.

## 4. Four Core Services

1. **Azure Virtual Machines** – Provides virtual machines for running applications and workloads.
2. **Azure Blob Storage** – Provides scalable object storage.
3. **Azure Virtual Network** – Provides networking capabilities for Azure resources.
4. **Azure SQL Database** – Provides a managed relational database service.

## 5. Three Advantages

1. Azure integrates strongly with Microsoft technologies and enterprise environments.
2. Azure provides a wide range of cloud services.
3. Azure supports hybrid cloud and enterprise workloads.

## 6. Typical Enterprise Use Cases

Enterprises use Azure for Windows-based applications, Microsoft 365-related environments, databases, enterprise applications, hybrid cloud deployments, artificial intelligence, analytics, and virtual infrastructure.
