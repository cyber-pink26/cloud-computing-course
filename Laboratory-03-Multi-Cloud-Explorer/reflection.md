# Mission Reflection

Among AWS, Microsoft Azure, and Google Cloud Platform, the cloud platform that impressed me the most is AWS. I was impressed by the wide range of services it provides for different types of applications and organizations. AWS can support startups as well as large enterprises, making it a flexible platform for different cloud computing needs.

AWS, Azure, and GCP have many similarities. All three provide computing, storage, networking, database, identity, and other cloud services. They also allow organizations to scale their resources and deploy applications using global cloud infrastructure. Although their services have different names, many of them perform similar functions, such as virtual machines, object storage, SQL databases, and Kubernetes services.

Business requirements have an important role in selecting a cloud provider. An organization needs to consider its budget, existing technologies, application requirements, performance, scalability, security, and future growth. For example, Azure is a strong choice for an organization already using Microsoft technologies, while Google Cloud can be suitable for AI and machine learning workloads.

Acting as a Cloud Solutions Consultant taught me that choosing a cloud provider is not simply about selecting the most popular platform. The decision should be based on the specific needs and goals of the client. I also learned how to compare cloud services and match them to different business scenarios.

My GitHub Cloud Computing Portfolio has improved significantly after completing this mission. It now contains organized research, comparison tables, client recommendations, Linux investigation results, screenshots, and a reflection. This activity helped me practice technical documentation using Markdown while also improving my understanding of AWS, Azure, and Google Cloud.
