# Mission Reflection

This laboratory activity helped me understand the basic environment and responsibilities involved in cloud computing. Using KillerCoda allowed me to work with an Ubuntu Linux server without needing to install a virtual machine on my own computer. I learned how to create a user account, give it sudo access, navigate the Linux file system, and collect important system information.

One of the most useful parts of the activity was learning Linux commands such as `lscpu`, `free`, `df`, `pwd`, and `hostname`. These commands helped me understand the resources and configuration of a cloud-based Linux environment. I also learned that documenting system information is important because cloud engineers need to know what resources are available when managing infrastructure.

Creating and organizing the GitHub portfolio also showed me the importance of technical documentation. Keeping laboratory outputs, screenshots, and Markdown files in one repository makes it easier to track progress and review completed work. GitHub also provides version control, which is useful when working on technical projects.

Overall, this mission gave me a better understanding of the basic skills needed before working with larger cloud platforms and infrastructure. It also helped me become more comfortable with Linux, cloud-based environments, Markdown, and GitHub. These skills will be useful in future laboratory activities involving cloud services, virtualization, containers, and system administration.
