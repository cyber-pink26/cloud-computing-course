# Laboratory 01 – Welcome to the Cloud

## Mission Overview

This laboratory activity introduced me to a cloud-based Linux environment using KillerCoda. I explored Ubuntu Linux, created a new user account, gathered system information, organized files and directories, and documented my work using Markdown and GitHub.

## Objectives

* Access and use a cloud-based Linux environment using KillerCoda.
* Explore and navigate the Linux operating system.
* Gather basic system information.
* Organize files and directories using Linux commands.
* Create and maintain a professional GitHub repository.
* Document technical work using Markdown.

## Activities Performed

* Launched an Ubuntu 24.04 Linux Playground using KillerCoda.
* Created the `precodos` Linux user with Bash, a home directory, and sudo privileges.
* Logged in to the new user account.
* Recorded the current username, working directory, and hostname.
* Checked the Linux distribution and kernel version.
* Gathered CPU, memory, and disk information.
* Created and organized directories in the Linux environment.
* Created and viewed the `about-me.md` file.
* Created a GitHub repository and organized the laboratory files and screenshots.

## Skills Learned

I learned how to access and work in a cloud-based Linux environment, manage Linux users, check system resources, organize files and directories, create Markdown documentation, and use GitHub to maintain a technical portfolio.
