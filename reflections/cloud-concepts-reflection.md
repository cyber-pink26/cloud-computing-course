# Reflection: Cloud Concepts

Cloud computing has become an important part of my everyday life because I use different cloud services for communication, schoolwork, entertainment, and other activities. Three cloud services that I regularly use are **Google Drive, Messenger, and Canva**.

**Google Drive** is an example of **SaaS (Software as a Service)** because it provides ready-to-use applications and cloud storage through the internet without requiring me to manage the underlying servers or infrastructure. It uses a **Public Cloud** deployment model because the service is provided over the internet to many users. I use Google Drive to store, access, and share school files from different devices.

**Messenger** is also a **SaaS** application because users can directly access its messaging and communication features without managing the software or hardware behind it. It follows a **Public Cloud** deployment model because its services are hosted by the provider and made available to users through the internet. Messenger is useful for communicating with classmates, friends, and group members.

**Canva** is another example of **SaaS** because it provides an online platform for creating presentations, posters, infographics, and other designs. I do not need to install or maintain the servers that run Canva. It can be classified as a **Public Cloud** because the platform is accessible online to many users.

I also learned that **Git and GitHub are important for cloud projects**. Version control allows developers to track changes, restore previous versions, and identify who made specific changes. This is especially important when working with cloud infrastructure because a small configuration error can affect applications, databases, or other resources. GitHub helps team members collaborate by allowing them to share code, review changes, create branches, and merge approved updates.

Overall, learning about cloud concepts helped me understand that cloud services are not only convenient applications but also systems that require proper management, collaboration, and version control.
